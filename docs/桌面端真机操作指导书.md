# PhantomFilmer 桌面端真机操作指导书

本指导书适用于 Electron 桌面飞控台。GUI 提供人物建档/选择、真机连接、直接起飞、
普通/侧向/前向自动跟随、手动接管、停止和急停；视频会显示人物框和 `STATE` 状态。
Fake、dry-run、算法自测与自然语言 Console 仍使用 CLI。架构边界见
[07-桌面端架构与安全边界](07-桌面端架构与安全边界.md)。

## 1. 安装包

优先支持：

- Linux x64：AppImage。
- macOS Intel：x64 DMG。
- macOS Apple Silicon：arm64 DMG。
- Windows x64：NSIS 安装包，在 Linux/macOS 产物之后构建。

首轮产物不签名、不公证。下载 CI/Release 中与平台和架构匹配的文件，并用同一产物中的
`SHA256SUMS` 核对校验值。macOS 首次运行需在“隐私与安全性”中明确允许；Linux 需为
AppImage 添加执行权限。不要从不可信来源绕过系统安全提示。

## 2. 运行前准备

- 安装桨叶保护罩，确认电池充足。
- 打开无人机，电脑连接 `RMTT-XXXXXX` Wi-Fi；无互联网属于正常现象。
- 关闭 VPN、代理和会抢占路由的虚拟网卡。
- 关闭 CLI 飞行进程及其他 Tello 控制软件。
- 确认上、下、前、后和两侧均无人、无障碍物。

## 3. 启动与诊断

启动 `PhantomFilmer` 后，Electron main 会创建随机会话令牌、启动内置 Python sidecar、
读取 ready JSON 并执行认证健康检查。renderer 不知道令牌、端口或 sidecar 路径。

若出现“本地后端未运行”，界面会显示应用版本、日志目录和错误原因。真机未起飞时可
点击“重启后端”。若最后一次遥测显示真机在空中，应用会禁止自动重启：保持目视真机，
不要反复启动软件，按现场应急流程确认落地。

即使界面显示允许重启，只要中断发生在起飞请求期间，也必须先目视确认真机已经落地。
物理起飞可能发生在状态响应返回之前，此时 GUI 的最后状态可能仍显示地面。

诊断与飞行审计均写入系统标准 `userData/logs`，不会写入安装目录。常见位置：

- Linux：`~/.config/PhantomFilmer/logs`。
- macOS：`~/Library/Application Support/PhantomFilmer/logs`。
- Windows：`%APPDATA%\PhantomFilmer\logs`。

## 4. 连接与五项预检

点击“连接真机”后，sidecar 才发送 SDK 握手并开启视频。起飞必须同时通过：

1. SDK 连接正常。
2. 收到有效视频帧。
3. 电量不低于 20%。
4. 底部 ToF 高度可用。
5. 前向 ToF 可用或处于超量程状态。

视频使用一次性短期本地 URL；普通飞行命令只通过 preload 白名单转发。

## 5. 起飞与手动控制

- 起飞、正常降落和紧急降落都要在 4 秒内再次点击确认；键盘 `Q`（停止降落）与 `E`（急停）同样需要在 4 秒内按两次才执行。
- 手动接管后控制板以半透明 HUD 形式叠加在视频画面底部，不遮挡其他区域；HUD 内可关闭“键盘控制”开关（关闭后键盘不再产生飞行指令，屏幕控制板不受影响）。在输入框内打字时所有飞行键自动失效。
- 键盘：`W/S` 前后、`A/D` 左右、`R/F` 升降、`J/L` 偏航、空格悬停。
- 速度档位为 15、20、30；sidecar 最终限幅为 `[-35, 35]`。
- 松开按键或窗口失焦会主动悬停；0.4 秒看门狗独立清零失联 RC。
- 前向 ToF 无效、过期或 60 cm 内有障碍时禁止前进。
- 40 cm 以下禁止继续下降，200 cm 以上禁止继续上升。
- 正常降落保留视频和 SDK 连接；顶栏“断开真机”仅在地面且无任务时可用。

sidecar 在独立手动飞行中持续监视电量、最大高度和底部 ToF 读取状态；低电、超高或连续
读取失败会清零并主动降落。高度无效或超过 2 秒未更新时，任何升降指令都会被拒绝。

## 6. 人物建档与自动任务

1. 在真机断开时，在左栏“人物档案”tab 选择已有档案，或输入新档案名点击“新建档案”并选择多张清晰照片；每张照片必须只含一个目标人物。选择后界面显示照片数量，点击“确认建档”才写入；同名时会询问是否覆盖，取消不会改动旧档案。
2. 切换到“起飞准备”tab：确认任务类型（人物跟拍 / 固定航线演示）、是否启用前向 ToF 避障（仅普通跟随模式生效），并核对五项预检清单逐项通过。
3. 连接真机，点击“起飞”，并在 4 秒内再次点击“确认起飞”。无人机起飞后自动上升至 150 cm。
4. 到达悬停高度后视频上会出现醒目的模式选择横幅，在模式行选择“普通跟随”“侧向跟随”“前向跟随”或“手动接管”；模式行右侧可“暂停任务”（键盘 `P`），暂停后任务悬停冻结、再按一次继续。
5. 空中切换到手动后才出现键盘与 HUD 控制板；再次选择手动会退出手动、重新识别并恢复自动跟随。
6. “停止并降落”和“急停”均需二次确认。左栏“运行事件”tab 实时显示任务、安全降落与 RC 租约事件；顶栏“日志”按钮直接打开后端日志目录。

人物必须先进入飞行画面，ReID 才能锁定并跟随；遮挡、换衣、逆光或运动模糊都可能导致
目标丢失。侧向/前向模式绕过前向自动避障，必须确保全向净空。视频画面按原始比例放大
铺满视频区（上下边缘可能被轻微裁切），识别框以画面内容为准。

## 7. 安全退出

关闭窗口时应用会查询最后飞行状态。若真机在空中，必须确认“安全降落并退出”；应用
先悬停、降落，再关闭视频、SDK、后台线程和 sidecar。清理超时会显示第二个明确风险
提示；只有目视确认真机已落地或已准备实体应急措施时才能选择强制退出。

## 8. 验收清单

- 断网时应用可离线启动，未连接真机前不请求视频。
- 五项预检与起飞按钮门控正确；界面在 1040×760 与 1480×980 下均无滚动条。
- 起飞、正常降落、紧急降落均需二次确认（键盘 Q/E 同样）。
- 按住方向持续刷新 RC，松开立即悬停。
- 近距离前向障碍阻止前进，高度上下限阻止越界。
- 低电、超高和连续底部 ToF 失败触发手动飞行安全降落。
- 人物建档只能在断开时执行；模型资产缺失时起飞按钮禁用。
- 自动任务直接起飞至 150 cm 后允许切换普通、侧向、前向和手动接管；暂停/继续可用。
- 避障开关与任务类型正确传入任务启动命令。
- 正常降落后视频保持连接；视频中断后可自动重连或手动重建。
- sidecar 崩溃后所有控制立即禁用；最后状态为空中时不自动重启；sidecar 挂起（进程存活但无响应）在约 15 秒内被心跳判定并提示重启。
- 空中关闭窗口时先完成降落和清理。

自动化测试不替代真机验收。每个平台安装包仍需分别执行安装、离线启动、权限提示、
窗口关闭和卸载冒烟测试。
