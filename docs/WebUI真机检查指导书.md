# PhantomFilmer WebUI 真机检查指导书

这份指导书用于让收到 GitHub 分支的检查者，在自己的电脑上安装依赖、连接
RoboMaster TT / Tello Talent，并检查本地 WebUI 与内嵌真机视频。

## 1. 交付包里已经包含什么

- `web_api/`：只监听本机的最小真机 HTTP 服务与 Tello 适配代码。
- `webui/`：亮色 Web 前端源码。
- `scripts/install_webui.sh`：联网安装脚本。
- `scripts/start_webui.sh`：离线真机启动脚本。
- WebUI 所需的 Python 与 Node 依赖清单和锁文件。
- 自动化测试和本文档。

这是精简交付分支，不包含 PhantomFilmer 完整飞控、自动跟随、ReID、控制台或历史
源码。也不包含 Python 虚拟环境、`node_modules`、Next.js 构建结果、模型权重、
人物照片、人物特征档案、飞行日志，以及任何本机密钥。

## 2. 检查者需要自行准备

### 硬件

- RoboMaster TT / Tello Talent 真机和已充电电池。
- 桨叶保护罩。
- 一台带 Wi-Fi 的 macOS 或 Linux 电脑。
- 首次安装时可用的互联网连接。

### 系统软件

- Git。
- Python 3.10–3.12，建议 Python 3.11。
- Node.js 20.9 或更高版本，建议 Node.js 22 LTS；Node 安装包应包含 npm。

本交付包只用于检查真机连接、电量、高度、顶部 ToF 和内嵌视频，不包含人物识别、
起飞或自动跟随功能。

## 3. 第一次安装（必须在有互联网时完成）

克隆仓库并切换到交付分支：

```bash
git clone --branch feat/webui-real-device-handoff --single-branch \
  https://github.com/player-Muteki/PhantomFilmer.git
cd PhantomFilmer
```

检查版本：

```bash
python3 --version
node --version
npm --version
```

执行统一安装：

```bash
bash scripts/install_webui.sh
```

脚本将创建 `.venv-webui`、安装 Python 真机依赖、执行 `npm ci`，并提前完成 WebUI
生产构建。完成后，无人机 Wi-Fi 没有互联网也能运行。

## 4. 连接真机前的地面检查

1. 安装桨叶保护罩，把无人机放在水平、空旷、光照充足的位置。
2. 本次 WebUI 检查只连接、读取遥测和视频，不会主动起飞。
3. 打开无人机，等待 Wi-Fi 指示灯进入可连接状态。
4. 在电脑 Wi-Fi 列表中连接 `RMTT-XXXXXX`。
5. 暂时关闭 VPN、代理、网络加速器和会抢占路由的虚拟网卡。

连接无人机 Wi-Fi 后电脑通常没有互联网，这是正常现象。本地浏览器、
`127.0.0.1` 和无人机 `192.168.10.1` 仍可正常通信。

## 5. 启动 WebUI

在仓库根目录运行：

```bash
bash scripts/start_webui.sh
```

保持终端窗口打开，然后在浏览器访问：

```text
http://127.0.0.1:3000
```

启动脚本会同时运行：

- `127.0.0.1:3000`：WebUI。
- `127.0.0.1:8765`：Python 真机服务。

两项服务都只监听本机，不向局域网或互联网开放。

## 6. 检查连接和视频

1. 页面初始应显示“真机未连接”和“视频未开启”。
2. 未连接时页面不应请求无人机视频。
3. 点击“连接真机”。
4. 后端向 `192.168.10.1:8889` 发送 `command`，必须收到 `ok`。
5. 页面显示真机电量和高度；若顶部扩展 ToF 不可用，会显示“超量程/不可用”。
6. SDK 连接成功后后端才发送 `streamon`。
7. 收到首个有效帧后，实时画面应出现在页面左侧内嵌区域。
8. 操作系统中不应出现名为 PhantomFilmer 的独立视频窗口。

“停止任务”用于清零控制量、关闭视频和释放连接。当前 WebUI 不提供起飞入口，因此
正常地面检查结束时应使用“停止任务”。“紧急降落”需要在 4 秒内点击两次确认，
只应在真机已经意外处于空中时使用。

## 7. 推荐验收记录

- 页面是否能在无互联网状态打开。
- 未连接真机时是否完全没有视频。
- `command -> ok` 是否成功。
- 电量和底部 ToF 高度是否显示。
- 视频是否只在浏览器内出现。
- 点击“停止任务”后视频是否关闭、状态是否回到未连接。
- 刷新页面后是否默认保持未连接，不自动重连。
- 终端中是否出现超时、解码或端口占用错误。

## 8. 常见故障

### 点击连接后提示 UDP timeout

- 确认当前 Wi-Fi 是 `RMTT-XXXXXX`。
- 确认无人机地址仍为 `192.168.10.1`。
- 关闭 VPN、代理和其他网络接口后重试。
- 运行 `curl http://127.0.0.1:8765/api/health`，先确认本地真机服务在线。

### 页面可以打开，但连接按钮报真机服务不可用

- 检查启动脚本所在终端是否仍在运行。
- 检查 `8765` 端口：

  ```bash
  curl http://127.0.0.1:8765/api/health
  ```

- 如果端口被占用，停止旧的 PhantomFilmer 进程后重新运行启动脚本。

### 已连接但没有视频

- 等待 5–10 秒，观察终端是否出现视频解码错误。
- 点击“停止任务”，确认释放旧视频接收器后重新连接。
- 检查防火墙是否阻止 Python 接收无人机 UDP 视频。
- 不要同时运行 `main.py --mode camera` 或其他占用视频流的程序。

### 切换到无人机 Wi-Fi 后网页打不开

- 必须访问 `http://127.0.0.1:3000`，不要使用云端预览地址。
- 确认已经在有互联网时执行过 `install_webui.sh`。
- 不要删除 `webui/.next`、`webui/node_modules` 或 `.venv-webui`。

## 9. 结束检查

先点击页面上的“停止任务”，再回到启动终端按 `Ctrl+C`。启动脚本会关闭前端、
真机服务和残留视频连接。最后可切回日常 Wi-Fi。
