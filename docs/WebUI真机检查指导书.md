# PhantomFilmer WebUI 真机操作指导书

本指导书用于安装和运行独立的 PhantomFilmer 真机 WebUI。系统仅连接
RoboMaster TT / Tello Talent。

## 1. 交付内容

- `web_api/`：本机真机服务、Tello 适配、起降和手动 RC 安全控制。
- `webui/`：亮色响应式 Web 前端与内嵌视频界面。
- `scripts/install_webui.sh`：联网安装脚本。
- `scripts/start_webui.sh`：离线真机启动脚本。
- Python、Node 依赖清单、自动化测试和本文档。

不包含 Python 虚拟环境、`node_modules`、构建结果、人物照片、模型权重、日志或密钥。

## 2. 本地准备

- RoboMaster TT / Tello Talent、充足电量和桨叶保护罩。
- 带 Wi-Fi 的 macOS 或 Linux 电脑。
- Git、Python 3.10–3.12。
- Node.js 20.9 或更高版本，建议 Node.js 22 LTS，且包含 npm。
- 首次安装时可用的互联网连接。

## 3. 首次联网安装

```bash
git clone --branch feat/webui-real-device-handoff --single-branch \
  https://github.com/player-Muteki/PhantomFilmer.git
cd PhantomFilmer
bash scripts/install_webui.sh
```

安装脚本会创建 `.venv-webui`，安装 Python 与 Node 依赖并完成生产构建。此后连接
没有互联网的无人机 Wi-Fi 也能运行。

## 4. 启动本地 WebUI

1. 打开无人机，等待 `RMTT-XXXXXX` Wi-Fi 出现。
2. 电脑连接该 Wi-Fi；“无互联网连接”属于正常现象。
3. 关闭 VPN、代理和会抢占路由的虚拟网卡。
4. 在项目根目录运行：

   ```bash
   bash scripts/start_webui.sh
   ```

5. 保持终端运行，在浏览器打开 `http://127.0.0.1:3000`。

WebUI 监听 `127.0.0.1:3000`，真机服务监听 `127.0.0.1:8765`，均不对外网开放。

## 5. 连接与视频

1. 页面初始必须显示“真机未连接”和“视频未开启”。
2. 点击“连接真机”，后端向 `192.168.10.1:8889` 发送 SDK 握手。
3. 只有收到 `ok` 后才执行 `streamon`。
4. 收到首个非占位视频帧后，画面才会出现在网页内嵌区域。
5. 不会创建 OpenCV 或系统独立视频窗口。

## 6. 起飞前检查

起飞按钮只有以下五项全部通过后才会启用：

- SDK 连接正常。
- 收到有效视频帧。
- 电量不低于 20%。
- 底部 ToF 高度可用。
- 前向 ToF 可用或处于超量程状态。

安装桨叶保护罩，把无人机放在水平、空旷地面，人工确认上、下、前、后和两侧均
无人员与障碍物。页面检查不能替代人工安全判断。

## 7. 起飞、手动飞行与降落

1. 点击一次“起飞”，按钮会变成“确认起飞”。
2. 在 4 秒内再次点击才会发送起飞指令。
3. 起飞完成后手动控制区自动启用。
4. 按住网页按钮或键盘持续运动，松开立即悬停。
5. 键盘映射：`W/S` 前后、`A/D` 左右、`R/F` 升降、`J/L` 左右偏航、空格悬停。
6. 可选择 15、20、30 三档速度；后端将所有 RC 通道限制在 `[-35, 35]`。
7. 前向 ToF 无效、过期或 60 cm 内有障碍时禁止前进。
8. 40 cm 以下禁止继续下降，200 cm 以上禁止继续上升。
9. 控制指令超过 0.4 秒未刷新时，后端看门狗自动清零并悬停。

“正常降落”需要二次确认，降落后保留视频与连接。“停止并断开”在空中时会先降落，
再关闭视频和 SDK 连接。“紧急降落”也需要二次确认，只用于紧急情况。

## 8. 推荐验收项目

- 无互联网时能否打开 `http://127.0.0.1:3000`。
- 未连接真机时是否完全不请求视频。
- SDK、电量、底部 ToF、前向 ToF 和视频预检是否正确。
- 视频是否只出现在浏览器内。
- 起飞是否必须二次确认。
- 松开手动控制后是否立即悬停。
- 前方近距离障碍是否会阻止前进。
- 正常降落后视频是否保持连接。
- 空中点击“停止并断开”是否先降落。

## 9. 常见故障

### UDP timeout

- 确认当前 Wi-Fi 是 `RMTT-XXXXXX`。
- 确认无人机地址为 `192.168.10.1`。
- 关闭 VPN、系统代理和网络加速器。
- 用 `curl http://127.0.0.1:8765/api/health` 检查本地服务。

### 页面可以打开但没有视频

- 等待 5–10 秒并观察终端解码错误。
- 点击“停止并断开”后重新连接。
- 检查防火墙是否阻止 Python 接收 UDP 视频。
- 不要同时运行其他占用无人机视频流的软件。

### 网页打不开

- 使用 `http://127.0.0.1:3000`，不要使用云端地址或 HTTPS。
- 确认已在有互联网时运行 `install_webui.sh`。
- 保持 `start_webui.sh` 所在终端窗口运行。

## 10. 结束操作

若真机在空中，先执行“正常降落”。随后点击“停止并断开”，回到终端按 `Ctrl+C`，
最后切回日常 Wi-Fi。
