# PhantomFilmer 桌面端开发构建指南

本指南用于从源码构建包含 Electron 前端、Python sidecar、YOLOv8n、OSNet 和
JointBDOE 的完整 PhantomFilmer 桌面应用。模型权重、人物档案和构建产物不会提交到
Git；构建脚本会下载、校验并嵌入所需模型。

## 1. 支持范围

- macOS Apple Silicon：在 Apple Silicon Mac 上原生构建 arm64 DMG。
- macOS Intel：在 Intel Mac 上原生构建 x64 DMG。
- Linux x64：在 Linux x64 上原生构建 AppImage。
- Windows x64：使用 GitHub Actions 的 Windows 构建产物；当前本地一键脚本是 Bash
  脚本，不承诺在 Windows shell 上运行。

PyInstaller 与 Electron 都会打入当前平台的原生二进制，因此不要在 ARM Mac 上承诺
交叉构建 Intel Mac 包。需要另一种架构时，请在对应架构机器上构建，或下载 CI 的产物。

## 2. 首次构建前的工具

安装以下工具，随后重开终端：

- Git 2.40 或更高。
- Python **3.12**（不是 macOS 自带的旧 Python）。
- Node.js **22 LTS** 或更高。
- macOS：Xcode Command Line Tools，执行 `xcode-select --install`。
- 至少 12 GB 可用磁盘空间和首次构建所需的网络连接。

macOS 使用 Homebrew 时可执行：

```bash
brew install git python@3.12 node@22
xcode-select --install
```

确认版本：

```bash
git --version
python3.12 --version
node --version
npm --version
```

## 3. 一键隔离构建

```bash
git clone https://github.com/player-Muteki/PhantomFilmer.git
cd PhantomFilmer
bash scripts/build_desktop_app.sh
```

脚本会依次：

1. 在仓库中创建 `.venv-desktop-build`，所有 Python 构建依赖都安装在这里。
2. 使用 `desktop/package-lock.json` 的 `npm ci` 安装 Node 依赖。
3. 下载 YOLOv8n、OSNet 与 JointBDOE 权重，逐个验证 SHA-256；JointBDOE 源码固定到
   脚本中声明的 Git commit。
4. 用 PyInstaller 构建并冒烟测试 Python sidecar，真实加载三套视觉模型。
5. 构建 Electron 安装包；macOS 额外执行 `hdiutil verify`。
6. 在 `release/` 写入安装包及 `SHA256SUMS`。

构建过程不会使用系统 Python 的第三方包，也不会把模型或人物档案提交到 Git。Torchreid
因其旧版构建后端使用 `--no-build-isolation`，但该安装仍限制在
`.venv-desktop-build` 内，不会污染全局环境。

如果 Python 3.12 不在 `python3.12` 路径，可显式指定：

```bash
PYTHON_BIN=/opt/homebrew/bin/python3.12 bash scripts/build_desktop_app.sh
```

## 4. 模型与人物档案

完整桌面包使用的检测模型是 **YOLOv8n**，对应 `config.yaml` 的
`vision.person_detector_model: weights/yolov8n.pt`。请勿按旧文档换成 YOLO11n；更换
检测或 ReID 模型会改变模型哈希，已有 ReID 人物档案将被安全地拒绝加载，需要重新建档。

人物档案不会包含在安装包或 Git 仓库中。桌面 App 的档案位置是 Electron 的 `userData`：

- macOS：`~/Library/Application Support/phantomfilmer-desktop/reid_profiles/`
- Linux：`~/.config/phantomfilmer-desktop/reid_profiles/`
- Windows：`%APPDATA%/phantomfilmer-desktop/reid_profiles/`

升级 App 时保留该目录。需要重新录入同名人物时，界面会先询问是否覆盖；确认覆盖后才会
选择新照片并生成新的特征文件。

## 5. 验证与故障排查

构建前或改动代码后执行：

```bash
cd desktop
npm test
npm run typecheck
cd ..

# 构建环境刻意不包含测试工具；用独立的测试环境运行 Python 测试。
python3.12 -m venv .venv-test
.venv-test/bin/python -m pip install -r requirements-dev.txt
.venv-test/bin/python -m pytest -q tests
```

常见问题：

- `缺少 Python 3.12`：安装 Python 3.12，或用 `PYTHON_BIN` 指定其完整路径。
- 模型下载或校验失败：检查网络；脚本不会接受 SHA-256 不匹配的模型文件。
- macOS 首次打开提示开发者无法验证：在“系统设置 → 隐私与安全性”中明确允许该应用。
- App 显示后端离线：查看 `~/Library/Application Support/phantomfilmer-desktop/logs/` 中的
  `sidecar-process.log` 与 `sidecar.log`；不要删除 `reid_profiles/`。

## 6. CI 与发布产物

`.github/workflows/desktop-build.yml` 在干净的 macOS、Linux 和 Windows Runner 上构建
对应原生包并上传工件。发布或合并前应确认至少 macOS arm64 的 workflow 通过；该结果是
对“从空机器构建完整功能 App”的最终验证。
