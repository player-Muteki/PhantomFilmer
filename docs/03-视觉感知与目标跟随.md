# 03 · 视觉感知与目标跟随

> [返回总入口](README.md) · 上一篇：[02-系统架构与生命周期](02-系统架构与生命周期.md) · 下一篇：[04-搜索避障与运动仲裁](04-搜索避障与运动仲裁.md)
>
> 本文从统一检测契约出发，说明红色 / ArUco / 人物 ReID 三种检测器、检测器工厂、ReID 注册与档案，以及 `FollowController` 的跟随控制、锁定与重新确认语义。

## 1. 统一检测契约

所有检测器实现 `DetectorProtocol`（[vision/detector_protocol.py:9](../vision/detector_protocol.py#L9)），两个方法：

- `detect(frame) -> DetectionResult`：返回**字典**结果。
- `draw_debug(frame, result) -> frame`：返回调试渲染帧。

`DetectionResult = Dict[str, Any]`。下游（`FollowController`、`FollowSession`、`MotionArbiter`）只依赖字典键，因此**切换检测器不需要改动控制层**（[README.md:91](../README.md#L91)）。

字典关键字段（约定，实际由各实现填充）：

| 键 | 类型 | 语义 |
|----|------|------|
| `found` | bool | 本帧是否发现目标 |
| `is_predicted` | bool | 是否为“预测/复用旧值”（临时丢失容忍） |
| `ambiguous` | bool | 是否身份歧义（ReID 专用） |
| `center` / `target_center_x` / `target_center_y` | int | 目标中心 |
| `area` | float | 目标面积（像素） |
| `bbox` | (x,y,w,h) | 目标框 |
| `area_ratio` | float | 面积/帧面积（ReID 填充） |
| `detector_type` | str | `red` / `aruco` / `person_reid` |

> **事实边界**：`is_predicted` 与 `ambiguous` 由具体检测器填充；红色检测器恒为 `is_predicted=False`，ArUco 只在临时丢失容忍窗口内为 `True`，ReID 在歧义 margin 内为 `ambiguous=True`。

## 3. 红色检测 `TargetDetector`

[vision/target_detect.py:10](../vision/target_detect.py#L10)

- HSV 双阈值（红在色环两端）：`0-8` 与 `172-180`（[target_detect.py:75](../vision/target_detect.py#L75)）。
- 用 RGB 主色过滤强化“纯红”：`red>120` 且 `red > green*1.45` 且 `red > blue*1.70` 且 `(red-green)>45`（[target_detect.py:84](../vision/target_detect.py#L84)）。
- 形态学开/闭运算去噪（[target_detect.py:95](../vision/target_detect.py#L95)）。
- 轮廓检测取最大外接矩形；面积低于 `max(min_area, 帧面积*min_area_ratio)` 视为无目标（[target_detect.py:48](../vision/target_detect.py#L48)）。
- 配置键：`detector_min_area`（默认 500）、`detector_min_area_ratio`（默认 0.002）。

## 4. ArUco 检测 `ArucoTargetDetector`

[vision/aruco_detect.py:24](../vision/aruco_detect.py#L24)

- 默认字典 `DICT_4X4_50`、目标 `ID=23`（与 [config.yaml:29-30](../config.yaml#L29) 一致）。
- 支持 16 种字典名白名单（[aruco_detect.py:16](../vision/aruco_detect.py#L16)）。
- **坐标/面积平滑**：指数移动平均，`smoothing_alpha=0.30`（[aruco_detect.py:238](../vision/aruco_detect.py#L238)）。
- **临时丢失容忍**：`temporary_lost_frames` 内返回 `found=True, is_predicted=True` 的旧值；当前 YAML 为 0（[config.yaml:32](../config.yaml#L32)），即立即报告丢失。
- `detect` 返回额外字段：`marker_id`、`corners`、`detector_type`（[aruco_detect.py:156](../vision/aruco_detect.py#L156)）。

## 5. 人物 ReID `PersonReIDDetector`

[vision/person_reid_detect.py:93](../vision/person_reid_detect.py#L93)

### 5.1 推理链路

1. **YOLO 行人检测**：`UltralyticsPersonDetector.detect_people`（[person_reid_detect.py:20](../vision/person_reid_detect.py#L20)），`classes=[0]`（person），`conf=person_detection_confidence`（当前 0.45）。
2. **裁剪与嵌入**：对每个人框裁剪，RGB 转换后送 `TorchreidFeatureExtractor.extract`（OSNet，[person_reid_detect.py:65](../vision/person_reid_detect.py#L65)）。
3. **相似度**：`features @ reference_feature` 余弦相似度（两者都已归一化）。
4. **接受条件**（[person_reid_detect.py:195](../vision/person_reid_detect.py#L195)）：
   - `best_similarity >= reid_similarity_threshold`（当前 0.65）；
   - 且 `best - second >= reid_ambiguity_margin`（当前 0.05），否则 `ambiguous=True`。
5. **临时丢失**：`reid_temporary_lost_frames`（当前 0）内返回预测值。

### 5.2 参考特征

- 照片路径解析：`_parse_reference_images`（[person_reid_detect.py:519](../vision/person_reid_detect.py#L519)）。
- 从参考照片计算：对每张照片用 YOLO 检测，要求**恰含一个人**（多/少都抛错），对该人物框做嵌入并取平均归一化（[person_reid_detect.py:384](../vision/person_reid_detect.py#L384)）。
- 也可直接加载已保存档案特征：`vision.reference_profile`（[person_reid_detect.py:146](../vision/person_reid_detect.py#L146)）。

### 5.3 惰性加载与准备

- 模型在 `_ensure_ready()`（[person_reid_detect.py:350](../vision/person_reid_detect.py#L350)）中分三步加载：YOLO → OSNet → 参考特征。
- `prepare()` 在起飞前调用（[person_reid_detect.py:236](../vision/person_reid_detect.py#L236)）；任何一步失败都会阻止起飞。
- 无 ReID 依赖时抛 `RuntimeError` 提示安装 `requirements-reid.txt`（[person_reid_detect.py:31](../vision/person_reid_detect.py#L31)）。

## 6. ReID 注册与本地档案

### 6.1 现场录入 `reid_enrollment.py`

- `collect_reference_images`（[reid_enrollment.py:208](../vision/reid_enrollment.py#L208)）：照片路径 / 目录 / 摄像头连拍三选一。
- `capture_reference_images`（[reid_enrollment.py:146](../vision/reid_enrollment.py#L146)）：SPACE 拍摄，Q 取消，保存到被 Git 忽略的 `data/reid_target/现场注册/`。
- `build_reid_runtime_config`（[reid_enrollment.py:51](../vision/reid_enrollment.py#L51)）：内存覆盖 `detector_type=person_reid` + ReID 距离带覆盖，**不写 YAML**。
- `TargetLockTracker`（[reid_enrollment.py:17](../vision/reid_enrollment.py#L17)）：统计“连续可信匹配”帧数；只接受 fresh（非 predicted、非 ambiguous）结果。用于旧地面锁定流程与 `target_search` 重新确认。

### 6.2 档案存储 `reid_profiles.py`

目录 `data/reid_profiles/<profile>/`（Git 忽略）：

| 文件 | 内容 |
|------|------|
| `embedding.npz` | 归一化平均特征（`np.savez_compressed`） |
| `manifest.json` | `schema_version=1`、`preprocessing_version="yolo-person-crop-rgb-osnet-v1"`、模型哈希（`reid_model_sha256`/`person_detector_model_sha256`）、参考照片 sha256 列表 |

- **原子写**：`_atomic_save_embedding` / `_atomic_write_json` 用 `tempfile.mkstemp` + `os.replace`（[reid_profiles.py:196](../vision/reid_profiles.py#L196)）。
- **校验加载**：`load_reid_profile` 校验 schema 版本、预处理版本、模型哈希、`embedding_sha256` 与维度（[reid_profiles.py:95](../vision/reid_profiles.py#L95)）；权重或预处理变化会拒绝加载并要求重新注册。
- **隐私边界**：档案只存特征与照片哈希，不存照片本身；文档与 README 均提示勿用真实姓名、勿上传（[README.md:171](../README.md#L171)）。

## 7. 跟随控制 `FollowController`

[control/follow_control.py:44](../control/follow_control.py#L44)

### 7.1 三轴控制策略

`compute_command(target_result, frame_width, frame_height)`（[follow_control.py:140](../control/follow_control.py#L140)）：

1. **水平**：优先 yaw 转向，不使用左右平移。误差在死区内不输出，死区外按 `horizontal_error_ratio * yaw_kp` 比例计算并施加最小速度约束（[follow_control.py:293](../control/follow_control.py#L293)）。
2. **前后**：面积比例驱动。小于 `target_area_ratio_min` 全速前进，大于 `target_area_ratio_max` 全速后退，中间悬停（[follow_control.py:321](../control/follow_control.py#L321)）。
3. **上下**：目标在画面中心上方 → 上升，反之下降（固定 `vertical_speed`）（[follow_control.py:308](../control/follow_control.py#L308)）。
4. **对准减速**：存在 yaw 或上下修正时，把前后速度限制为 `forward_speed_while_aligning`（[follow_control.py:221](../control/follow_control.py#L221)）。
5. **最终限幅**：`safety_manager.limit_rc_command(...)`（[follow_control.py:239](../control/follow_control.py#L239)）。

### 7.2 LOCKED 锁定与退出滞回

- 进入 LOCKED：`is_stable`（本帧 fresh 检测 + 水平/垂直在死区内 + 面积在 `[min, max]` 带内）持续 `target_lock_stable_frames`（当前 15）帧（[follow_control.py:207](../control/follow_control.py#L207)）。
- LOCKED 期间不产生修正运动（`yaw=up_down=forward=0`），等待目标移出退出范围。
- 退出 LOCKED：目标移出**更宽的**退出面积带/死区（`_outside_lock_exit_range`，[follow_control.py:279](../control/follow_control.py#L279)），或本帧非 fresh 检测。
- 面积滞回：进入带 `0.030–0.080`，退出带 `0.025–0.085`（[config.yaml:62-76](../config.yaml#L62)），避免边界抖动反复锁定。

### 7.3 ReID 距离带覆盖

- ReID demo 运行时把 `reid_target_area_ratio_min/max`（`0.22/0.32`）和 `reid_target_lock_exit_*`（`0.20/0.34`）覆盖到共享键（[vision/reid_enrollment.py:78](../vision/reid_enrollment.py#L78)），因此跟随控制器面积带不同，但代码路径同一套。
- **不覆盖默认 ArUco 跟随**（注释明确，[vision/reid_enrollment.py:76](../vision/reid_enrollment.py#L76)）。

## 8. 锁定与重新确认语义（重要事实）

- **当前实现**：初始 ReID 接受由 `PersonReIDDetector.detect` 的阈值 + 歧义 margin 判定；单个 fresh 匹配帧即可返回 `found=True`（[person_reid_detect.py:195](../vision/person_reid_detect.py#L195)）。
- `ArbitrationEngine` 的首次接受门（`_target_ever_acquired`）：目标丢失时若 `found` 为真则走验证路径；`FollowFeature.propose` 返回 `FOLLOWING` 时才置 `_target_ever_acquired=True`（[control/kernel/arbitration.py:86](../control/kernel/arbitration.py#L86)）。
- **`reacquire_frames=5`**（[config.yaml:131](../config.yaml#L131)）：约束 `TargetSearchController` 搜索后的**重新确认**（`_reacquire_tracker`，[control/target_search.py:93](../control/target_search.py#L93)），**不是**“起飞前连续五帧锁定”。
- 旧文档中“起飞前连续五帧锁定”的说法**当前不再成立**：`reid-demo` 直接由终端 `y` 授权起飞（[app/modes.py:459](../app/modes.py#L459)），`initial_target_lock_frames=0`（[app/modes.py:486](../app/modes.py#L486)）。
- `TargetLockTracker` 仍存在并被 `target_search` 复用，但语义是搜索后重新确认的帧数。

## 9. 摄像头与调试帧

- `CameraStream`（[vision/camera.py:8](../vision/camera.py#L8)）：包一层 `DroneAdapter.stream_on/get_frame/stream_off`；`read_frame` 在未开启时抛 `RuntimeError`。
- 调试帧由各检测器 `draw_debug` 绘制：红色画框/十字/面积文字，ArUco 画四边形/ID/面积，ReID 画候选框与相似度/距离带状态（`FAR/NEAR/OK`，[person_reid_detect.py:338](../vision/person_reid_detect.py#L338)）。

## 10. 已知限制与未验证假设

- **ReID 不识别真实身份**：只做外观匹配；俯视/遮挡/换衣/逆光/低分辨率都降低可靠性（[README.md:120](../README.md#L120)）。
- **默认 `temporary_lost_frames=0`**（[config.yaml:32](../config.yaml#L32)）：ArUco 丢失立即报告，不产生预测帧。
- **ReID 依赖可选**：无 `ultralytics`/`torchreid` 时 `person_reid` 无法运行；工厂创建不抛错，但首次 `detect`/`prepare` 抛错。
- **面积-距离标定**：ArUco 面积阈值需在真机前用 `follow-dry-run` 标定（[config.yaml:28](../config.yaml#L28)）。
- **未验证假设**：ReID 相似度阈值 0.65 与歧义 margin 0.05 是配置值，其鲁棒性未在真实人群场景下由本仓库验证。

## 12. 不保证的能力

- 不保证 ReID 在真实人群、遮挡、换衣下的可靠性；不保证面积-距离标定对真机成立。
- 不保证 ArUco 平滑/丢失容忍的数值在真实光照与运动模糊下表现一致。
- 不保证“起飞前连续五帧锁定”之类的旧语义仍然存在。
