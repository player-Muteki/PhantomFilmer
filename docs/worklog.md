## 2026-07-12

- 完成控制台大模型接入任务的主要交付：自然语言解析、本地规则回退、OpenAI 兼容 LLM 分类客户端、Action 白名单校验和异常安全返回 `UNKNOWN`。

- `FollowSession` 增加外部停止和急停请求入口，运行中的控制台命令会触发清零控制、退出跟随循环并走原有降落/关流清理路径。
- 收紧本地解析安全策略：对启动、停止、急停、退出类含糊问句返回 `UNKNOWN`，避免把询问误判为执行命令。
- 自动化测试覆盖自然语言解析、LLM HTTP 分类、异常返回、控制台调度、Fake 跟随和外部停止行为。
