## 1. 配置来源优先级

`app/config.py`：

| 层 | 机制 | 代码 |
|----|------|------|
| 1. 配置 YAML | `load_config()` 用 PyYAML（无 PyYAML 时回退解析器） | [app/config.py:11](../app/config.py#L11) |
| 2. CLI 参数 | `parse_args` | [main.py:44](../main.py#L44) |
| 3. 运行期内存覆盖 | `load_runtime_config(obstacle_enabled)` 覆盖 `obstacle.enabled` | [app/config.py:34](../app/config.py#L34) |
| 4. ReID 运行材料 | `build_reid_runtime_config()` 写入参考照片或档案 | [vision/reid_enrollment.py:51](../vision/reid_enrollment.py#L51) |
| 5. 环境变量 | `LLM_API_KEY`（LLM 客户端） | [console/llm_client.py:30](../console/llm_client.py#L30) |
| 6. 代码 fallback | 各构造器 `default=` 参数 | 见各节 |

回退解析器 `_load_config_without_yaml`（[app/config.py:69](../app/config.py#L69)）：只支持顶层标量 + `vision/obstacle/manual_control/target_search` 四个扁平块；遇到其他嵌套块抛 `ValueError` 而非静默丢弃。当前 YAML 还包含 `flight_audit/side_follow/front_follow`，因此当前完整配置实际要求安装 PyYAML；无 PyYAML 时会在首个不支持的嵌套块显式失败。

## 3. 运行期覆盖与兼容/闲置项

- **运行期覆盖**：`obstacle.enabled`（避障询问，[app/config.py:43](../app/config.py#L43)）；参考照片或档案由 `build_reid_runtime_config()` 写入内存配置。
- **兼容但当前未消费**：
  - `--lock-frames`（[main.py:112](../main.py#L112) → [app/modes.py:425](../app/modes.py#L425) `del`）。
  - `reid_lock_stable_frames`、`reid_lock_timeout_seconds`、`reid_confirmation_timeout_seconds`（[config.yaml:47-49](../config.yaml#L47)）：旧地面锁定流程的兼容参数，当前 `reid-demo` 直接由终端 `y` 授权起飞。
  - `obstacle.front_tof_clear_distance_cm`：初始化给 `clearance_distance_cm` 但主路径未读。
  - Planner 构造器中的 legacy 参数（`avoidance_yaw_speed` 等）：接受后 `del`（[control/obstacle_avoidance.py:82](../control/obstacle_avoidance.py#L82)）。
- **`takeoff_height_verify_*`**：默认关闭（[config.yaml:13](../config.yaml#L13)），启用后才生效。
- **桌面端常量不读 YAML**：`MIN_TAKEOFF_BATTERY=20`、`MAX_RC_SPEED=35`、`RC_WATCHDOG_SECONDS=0.4`、ToF/高度门均定义在 `web_api/server.py`；CLI 配置变化不会自动同步。
- **回退解析器缺口**：当前 `flight_audit/side_follow/front_follow` 未加入无 PyYAML 回退块白名单；缺少 PyYAML 时加载当前配置会显式失败。

| `tools/reid_offline_eval.py` | PRID 2011 离线评估（只测裁剪人物 ReID，不测飞控） |
| `tools/jointbdoe_angle_eval.py` | 本地图片朝向角、检测置信度和耗时验证，不测飞控 |

本地数据（全部被 Git 忽略）：`weights/`、`third_party/JointBDOE/`、`data/reid_target/`、`data/reid_profiles/`、`data/reid_test/`、`data/datasets/`、`logs/`。

项目标准权重是 `weights/yolo11n.pt`，程序设置 `YOLO_OFFLINE=1`，飞行现场不会自动联网下载。当前 `config.yaml` 的 `weights/yolov8n.pt` 来自 `893d075` 的意外回退，与代码默认、离线片段和测试不一致；运行前应改回 YOLO11n。替换检测权重后，人物档案哈希会失配，必须重新注册档案。

依赖复现边界：`scripts/setup_reid_env.sh` 将 torchreid 固定在 `f8cd150…`，但直接安装
`requirements-reid.txt` 会从未固定提交的 Git URL 获取当前版本，且 torch、torchvision、
pandas、seaborn、thop 未锁版本；两条安装路径可能产生不同环境。
`scripts/setup_jointbdoe.sh` 校验权重 SHA-256，但源码使用未固定提交的浅克隆。发布或
复现实验前应记录完整依赖锁和第三方源码提交。
