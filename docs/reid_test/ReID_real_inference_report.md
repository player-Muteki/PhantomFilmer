# PhantomFilmer ReID 真实模型推理测试报告

- 测试日期：2026-08-11
- 测试范围：离线模型加载、OSNet 特征匹配、YOLO 行人检测、项目检测器封装、性能和自动化回归
- 安全边界：未连接无人机、未打开真实摄像头、未发送任何飞控指令

## 结论

下载的 OSNet 与 YOLOv8n 权重可以正常加载，PhantomFilmer 的 `PersonReIDDetector` 可以完成真实模型推理。ReID 模型在本次 PRID 跨摄像机样本上具有较好的排序能力（AUC 0.9916），但项目默认相似度阈值 `0.65` 非常保守，同人召回率仅 44.6%。默认 YOLO 置信度 `0.45` 对 PRID 的低分辨率人物图也偏高，会漏检目标。

当前结果适合进入真实目标人物、真实摄像头画面的 `follow-dry-run` 标定阶段，不足以授权真机起飞跟随。

## 数据与方法

- 参考人物：PRID `person_0001`，摄像机 A 下 3 张参考图。
- 正样本：同一人物在摄像机 B 下的全部 83 帧。
- 负样本：摄像机 B 下另外 50 个身份，共 4,482 帧。
- 特征模型：`osnet_x0_25`，MSMT17 combine-all 预训练权重。
- 相似度：3 张参考特征归一化平均后，与候选特征计算余弦相似度。

权重加载时丢弃 `classifier.weight` 和 `classifier.bias`，这是把分类训练权重用于特征提取时的正常行为；512 维特征骨干已成功加载。

## PhantomFilmer 检测器封装

使用真实 Torchreid 特征提取器和项目 `PersonReIDDetector`，把人物裁剪图作为单候选输入：

- 阈值 0.65：高分同人通过（0.6922），低分同人拒绝（0.6206），异人拒绝（0.5096）。
- 阈值 0.60：两张同人均通过，异人仍拒绝。
- 返回的 `found`、`similarity`、`bbox` 和 `candidate_count` 符合项目协议。

## YOLO 与完整流水线

PRID 图片本身只有约 64×128，是裁剪后的人物图，不是完整摄像头画面。将其放大到 320×640 后测试：

- YOLO 置信度 0.45：两张同人图均未检出；一张异人图以 0.551 检出。
- YOLO 置信度 0.25：一张同人图以 0.257 检出，另一张仍未检出。
- 完整 YOLO → OSNet 流水线在 `YOLO=0.25、ReID=0.65` 时，成功接受高分同人并拒绝异人。

该结果不能直接推导真实无人机画面应使用 0.25，因为 PRID 分辨率和构图与 Tello 摄像头不同。真实 `follow-dry-run` 必须重新统计行人检测置信度。

## 建议

1. 保留真机配置不变，不要直接按 PRID 结果启飞。
2. 离线 `follow-dry-run` 可从 `person_detection_confidence: 0.25`、`reid_similarity_threshold: 0.60` 开始观察。
3. 用实际目标人物采集至少 5–10 张前、后、侧面和不同距离的全身参考图。
4. 录制包含目标人物、相似衣着干扰者、遮挡、逆光和进出画面的真实视频。
5. 以“零误跟”为首要目标重新选择阈值；如果 0.60 出现误跟，应提高阈值或扩大 `reid_ambiguity_margin`。
6. 在真实视频连续通过后，才考虑地面静态真机联调；不得直接进入起飞跟随。
